## AD5X

Внутри архива папка `config/`. Включены все зависимости `[include ...]` от `printer.cfg` и `moonraker.conf`, включая пользовательские файлы Z-Mod и конфигурации плагинов. Также сохранён файл переменных `mod_data/variables.cfg`.

Это файловый снимок настроек; он не содержит прошивку, установленные исполняемые файлы Z-Mod/плагинов или образ системы. При восстановлении должны присутствовать соответствующие версии Z-Mod и плагинов. Абсолютные пути конфигурации оставлены такими, как на исходном принтере.

## AD5M — архив, а не свежая выгрузка

Внутри `archived-2026-09/`. Исходные локальные файлы сохранены с их именами, включая несколько версий `macros`. Файлы `merged-config-from-log-earlier.cfg` и `merged-config-from-log-later.cfg` извлечены из последних блоков конфигурации в сентябрьских логах Klipper; сами логи в публичный архив не включены.

Этот комплект не подтверждён как текущая конфигурация AD5M и не выдаётся за свежий снимок Z-Mod. Объединённые снимки служат справочной резервной копией: не подключайте их одновременно с отдельными файлами тех же секций. Перед восстановлением выберите нужную версию и сверьте оборудование, прошивку, пути и калибровки. Когда принтер будет доступен, стоит заменить этот архив полной свежей выгрузкой.

## OrcaSlicer

Активный сохранённый профиль: `Flashforge AD5X 0.4 - My profile`.

Структура архива:

```text
user/current/machine/       текущие пользовательские профили AD5M и AD5X
user/current/process/       текущие пользовательские профили печати
user/current/filament/      текущие пользовательские материалы
user/legacy/process/        ранее сохранённые профили печати AD5M
user/legacy/filament/       ранее сохранённые профили материалов
system-dependencies/       точные родительские профили текущей библиотеки
legacy-system-dependencies/ точные недостающие родители из установленных старых OrcaSlicer
```

Материалы включают пользовательские SUNLU HS PLA, PLA Meta, PETG Sunlu, eSUN PLA-Basic / PETG-Basic для AD5X, а также более ранние SUNLU PETG, SUNLU eABS, eSUN ABS+ и TPU eSun. Старые профили могут сохранять ограничения совместимости с другими принтерами; их настройки не были автоматически переназначены на AD5M/AD5X.

Имена и связи `inherits` сохранены. Все цепочки наследования выбранных профилей разрешены по точным именам. Недостающие старые базовые профили взяты из уже установленных версий OrcaSlicer; они не заменены похожими современными профилями.

Это резервная копия JSON-профилей, а не единый экспорт `.orca_printer` и не проект `.3mf`. Для восстановления сначала сделайте копию своей папки конфигурации OrcaSlicer. Пользовательские JSON относятся к соответствующим папкам `machine`, `process`, `filament` активного пользовательского каталога. Текущее и старое дерево разделены, чтобы не смешивать версии случайно. Системные зависимости приложены для восстановления наследования и сравнения; не перезаписывайте ими всю системную библиотеку.

Температуры, потоки, ретракты, G-code и команды смены филамента не корректировались в этой задаче. Наличие сохранённого профиля не означает, что он заново откалиброван или проверен печатью.

## Публичная копия

Из копии удалены поля подключения OrcaSlicer и распознанные секреты. Не включены общий `OrcaSlicer.conf`, состояние аккаунта и синхронизации, `.info`, заводские JSON с облачными/сетевыми параметрами, необработанные логи и старые автоматические снимки AD5X. Список затронутых полей указан в MANIFEST без их значений.

Настройки на компьютере и принтерах не изменялись. Перед восстановлением нужно заново указать адреса подключения и необходимые ключи доступа.
